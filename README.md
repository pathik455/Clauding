# Clauding 🕹️

A sleek VS Code extension designed to let you play modern retro mini-games (like Neon Snake) directly inside VS Code while Claude or other AI agents are executing long-running tasks.

## ✨ Features

- **Quick Access Icon**: One-click launcher from the editor title bar and status bar.
- **Split Screen / Chat Style**: Opens directly beside your active work tabs (top-right side).
- **Zero Permission Prompts**: Seamless start—enter your username once and dive straight into gaming.
- **Modular Game Hub**: Choose your game from the launcher screen (built to easily support future games like Space Runner, Pong, etc.).
- **Modern Neon Aesthetics**: Dark glassmorphic design, smooth 60 FPS canvas rendering, glowing elements.
- **Built-in Synth Sound FX**: Dynamic real-time Web Audio synthesizer sounds for eating, movements, and game-over crashes without loading external MP3 files.
- **Online & Local Leaderboard**: Track high scores globally and locally across game sessions.

## 🚀 Getting Started

### Development & Installation
1. Install dependencies:
   ```bash
   npm install
   ```
2. Build the extension:
   ```bash
   npm run build
   ```
3. Press `F5` in VS Code to launch the Extension Development Host, or click the **Clauding** icon in the editor title bar / status bar to start playing!
